# ARNIX-Lampac

Развёртывание Lampac NextGen для тестирования интеграции Alloha с ARNIX Cinema.

## Что уже подготовлено

- Docker-образ основан на официальном `ghcr.io/lampac-nextgen/lampac:latest`.
- Конфигурация слушает порт Render из переменной `PORT`.
- Включён встроенный модуль Lampac Alloha API (в интерфейсе ARNIX Cinema показывается как «Алладин»). Секреты не подставляются пустыми значениями: модуль использует встроенные адреса по умолчанию.
- Секреты Alloha намеренно не хранятся в Git.

## Развёртывание на Render

1. Откройте Render и выберите **New → Blueprint**.
2. Подключите репозиторий `arnix858-lang/-ARNIX-Lampac`.
3. Render прочитает `render.yaml` и создаст Web Service.
4. После сборки откройте адрес сервиса и проверьте `/version?type=hash`.

Бесплатный Render может останавливать сервис после периода бездействия. На бесплатном плане постоянный диск недоступен, поэтому кеш может сбрасываться после перезапуска.

## Алладин (встроенный модуль Lampac на базе Alloha)

В ARNIX Cinema источник отображается под названием «Алладин». На стороне Lampac его встроенный модуль и маршруты имеют техническое имя `Alloha` / `alloha`. Конфигурация сохраняет включённый модуль и встроенные endpoint’ы Lampac; пустые `token`/`secret_token` больше не задаются принудительно в шаблоне. Если текущая версия API провайдера требует персональные credentials, их следует добавить в Render Environment только из собственного кабинета/официального источника.

## Проверка потока

После настройки авторизации проверим фильм с Kinopoisk ID `3793`. Важно отличить:
- JSON/список озвучек;
- прямую ссылку HLS, которую сможет воспроизвести Media3 ExoPlayer;
- iframe/ошибку авторизации.

Сам факт успешного запуска Lampac ещё не означает, что Alloha уже выдаёт рабочий видеопоток.
